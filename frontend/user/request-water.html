Priority Tiers

When available water is less than total municipal demand, the C engine processes requests using this strict order:

Priority 1: Emergency 100% Guaranteed
Priority 2: Hospital 100% Guaranteed
Priority 3: Essential Up to 90%
Priority 4: Household Up to 75%
Priority 5: Commercial Up to 50%
